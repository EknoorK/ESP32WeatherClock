# ESP32 E-Ink WeatherClock

WiFi-enabled weather clock built on the ESP-WROOM-32 microcontroller and a 2.9" Waveshare E-Paper display. 

This project fetches real-time meteorological data via the Open-Meteo REST API and renders a clean, dynamic UI. The firmware is written in C++ and focuses on non-blocking execution, hardware level display management, and robust network recovery.
